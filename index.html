    The rules

    What the lab asks Bob to build. Bookings 1, 2 and 3 each start in a different band.

    Time to departureRefund
    more than 7 days100%
    1 to 7 days50%
    under 24 hours, or already cancelled0%

    How this works. The page runs this repo's own Python code (the app/ folder: FastAPI and SQLite) inside your browser and talks to it through the app's own web routes. Nothing is sent to a server. Every visit starts with fresh demo data, and so does Start over.
